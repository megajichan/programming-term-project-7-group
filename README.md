# programming-term-project-7-group
# Logic Gate Simulation Engine
이 프로젝트는 논리 게이트 시뮬레이션 엔진입니다.

## 팀원 협업 안내
- **엄주현:** `main.cpp`의 영상처리 연동 주석 위치를 확인하여 `imageYUEE` 클래스를 통합하세요.
- **:** 시뮬레이션 후 생성되는 `circuit_data.csv`를 활용하여 최적 소자 추천 알고리즘을 구현하세요.
- **권재호:** `Simulator::runAll()`을 통해 시뮬레이션 결과를 GUI와 연동하세요.

## 사용법
1. 저장소를 클론(Clone) 받습니다.
2. 각자 담당한 모듈을 지정된 위치에 통합합니다.
3. 컴파일 후 시뮬레이션을 실행하여 결과를 확인합니다.
